# 刘科宏｜个人记录

一个以公开写作、分类与归档为核心的个人网站。

## 设计
- 券商研究报告式蓝白视觉
- 中文内容优先
- 文章、分类、归档与关于
- 不自动展示项目、经历或当前计划
- 推荐内容必须由作者明确指定

## 技术
- Astro 7
- TypeScript
- Markdown Content Collections
- GitHub Pages

## 本地运行
```bash
npm install
npm run dev
```

## 新建内容
复制 `content-templates/article.md` 至 `src/content/writing/`，补全字段。新内容默认保持草稿、私人且不推荐。
