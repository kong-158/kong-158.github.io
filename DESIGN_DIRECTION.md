# Design Direction V3

The site should feel like a personal magazine and research notebook, not a GitHub dashboard or SaaS landing page.

- Chinese-first editorial typography
- Warm paper background, ink blue, vermilion and cobalt accents
- No grid background, repository cards, status pills, marquee, or skill meters
- Projects use numbered editorial rows
- Notes use shelves/columns
- Homepage includes a custom Finance × CS × AI trajectory illustration
