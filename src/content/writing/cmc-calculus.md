## 第八章补记｜反常积分的两个换元信号（35、36）

### 方法判断｜什么时候想到“取倒数”？

这里有两种不同思路，不要混在一起：

**1. 倒数换元 `t = 1/x`：交换零点与无穷、把高次式改写为 `1/x` 的低次式。**

- **看区间**：如 `[1, +∞)` 可以变成 `(0, 1]`，但有无穷端点并不意味着一定要倒数换元。
- **看次数**：分母含 `x√(x²+ax+b)` 这类组合时，先提取 `x²`，再观察是否出现 `dx/x²`；因为 `t=1/x` 时有 `dx/x² = −dt`。
- **看对称**：含 `x+1/x`、`x²+1/x²`，或积分区间为 `(0,+∞)` 时，尝试 `x ↔ 1/x`，看能否构造对称关系。

对于 `a>0`，统一变换公式是 `∫ₐ^∞ f(x)dx = ∫₀^(1/a) f(1/t)/t² dt`；换元后**更简单**才值得使用。

**2. 表达式取倒数（有理化）：根式相减，平方差能凑常数。**

遇到 `√(x²+a²)−x`，先记 `(√(x²+a²)−x)(√(x²+a²)+x)=a²`，于是可把差转成 `a²/(√(x²+a²)+x)`。当 `a=1`，就是“凑 1”。

**速记：** 倒数换元看 **无穷区间 / 次数 / 对称性**；有理化看 **根式相减 / 平方差**。判断标准始终是变换后是否简化。

### 35｜倒数换元：把无穷区间折回有限区间

原题：`I = ∫₁^∞ dx / [x√(x² + 2x − 1)]`。

取 `t = 1/x`，则 `dx = −dt/t²`，上下限由 `1 → ∞` 变为 `1 → 0`，从而

`I = ∫₀¹ dt / √(1 + 2t − t²) = ∫₀¹ dt / √[2 − (t − 1)²] = π/4`。

**识别信号：** 在 `[1, +∞)` 上出现 `x√(x² + ax + b)` 一类结构，优先试 `t = 1/x`；根式中的二次项通常能化成易积分的形式。

### 36｜先凑 1 有理化，再用万能换元

原题：`I = ∫₀^∞ (√(x² + 1) − x)² dx`。

先看平方差：`(√(x² + 1) − x)(√(x² + 1) + x) = 1`，因此

`I = ∫₀^∞ dx / (√(x² + 1) + x)²`。

沿三角换元路线，令 `x = tan θ`，再用**万能代换** `u = tan(θ/2)`，有

`I = 2∫₀¹ (1 + u²)/(1 + u)⁴ du = 2/3`。

**更短的做法：** 直接设 `t = √(x² + 1) + x`，则 `x = (t − 1/t)/2`，所以

`I = 1/2 · ∫₁^∞ (t⁻² + t⁻⁴) dt = 2/3`。

**识别信号：** 见到 `√(x² + a²) ± x`，先利用平方差**凑出常数**、有理化；之后可用三角万能换元，也可直接设 `t = √(x² + a²) + x`。
