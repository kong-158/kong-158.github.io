## 一、核心公式

在 0 点展开：

`f(x) = f(0) + f'(0)x + f''(0)x²/2! + ... + f⁽ⁿ⁾(0)xⁿ/n! + o(xⁿ)`

做题时更重要的是记住常见函数的展开，并能熟练换元。

## 二、最常用的一组

| 函数 | Maclaurin 展开 |
| --- | --- |
| `e^x` | `1 + x + x²/2! + x³/3! + x⁴/4! + ...` |
| `sin x` | `x - x³/3! + x⁵/5! - x⁷/7! + ...` |
| `cos x` | `1 - x²/2! + x⁴/4! - x⁶/6! + ...` |
| `ln(1+x)` | `x - x²/2 + x³/3 - x⁴/4 + ...` |
| `ln(1-x)` | `-x - x²/2 - x³/3 - x⁴/4 - ...` |
| `1/(1-x)` | `1 + x + x² + x³ + ...` |
| `1/(1+x)` | `1 - x + x² - x³ + x⁴ - ...` |
| `(1+x)^α` | `1 + αx + α(α-1)x²/2! + α(α-1)(α-2)x³/3! + ...` |
| `arctan x` | `x - x³/3 + x⁵/5 - x⁷/7 + ...` |
| `arcsin x` | `x + x³/6 + 3x⁵/40 + 5x⁷/112 + ...` |

### 广义二项式

`(1+x)^α = 1 + αx + α(α-1)x²/2 + α(α-1)(α-2)x³/6 + O(x⁴)`

几个直接结论：

- `sqrt(1+x) = 1 + x/2 - x²/8 + x³/16 + O(x⁴)`
- `1/sqrt(1+x) = 1 - x/2 + 3x²/8 - 5x³/16 + O(x⁴)`
- `sqrt(1-x) = 1 - x/2 - x²/8 - x³/16 + O(x⁴)`

## 三、考试最常用的低阶形式

很多极限和估阶题只需要保留到第一项不消掉的位置：

- `e^x = 1 + x + x²/2 + x³/6 + o(x³)`
- `sin x = x - x³/6 + o(x³)`
- `cos x = 1 - x²/2 + x⁴/24 + o(x⁴)`
- `ln(1+x) = x - x²/2 + x³/3 + o(x³)`
- `1/(1+x) = 1 - x + x² - x³ + o(x³)`
- `(1+x)^α = 1 + αx + α(α-1)x²/2 + o(x²)`
- `arctan x = x - x³/3 + o(x³)`

## 四、换元

展开式真正高频的用法不是机械背诵，而是换元。

例如：

`e^(2x) = 1 + 2x + 2x² + 4x³/3 + ...`

`ln(1+x²) = x² - x⁴/2 + x⁶/3 + ...`

`cos(2x) = 1 - 2x² + 2x⁴/3 + ...`

## 五、常用等价无穷小

一级等价：

- `sin x ~ x`
- `tan x ~ x`
- `arcsin x ~ x`
- `arctan x ~ x`
- `e^x - 1 ~ x`
- `ln(1+x) ~ x`
- `1 - cos x ~ x²/2`
- `(1+x)^α - 1 ~ αx`

高阶消去以后常用：

- `sin x - x ~ -x³/6`
- `tan x - x ~ x³/3`
- `e^x - 1 - x ~ x²/2`
- `ln(1+x) - x ~ -x²/2`
- `cos x - 1 + x²/2 ~ x⁴/24`

## 六、最值得直接记住的七个

`e^x`、`sin x`、`cos x`、`ln(1+x)`、`1/(1-x)`、`(1+x)^α`、`arctan x`。

其他很多展开都可以从这几类通过换元、求导或积分得到。
